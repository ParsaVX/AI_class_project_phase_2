# سیستم توصیه‌گر فیلم و کتاب (آزمایشگاه هوش مصنوعی)

این پروژه مربوط به گام دوم آزمایشگاه هوش مصنوعی است که به پیاده‌سازی و طراحی یک سیستم توصیه‌گر (Recommender System) بین‌رشته‌ای برای فیلم و کتاب بر اساس گراف شباهت و الگوریتم‌های جستجو می‌پردازد.

## مشخصات پروژه
- **موضوع:** پیشنهاد هوشمند فیلم و کتاب بر اساس سلیقه کاربر
- **ابزارها و تکنولوژی‌ها:** پایتون، کتابخانه‌های پردازش داده و الگوریتم‌های جستجوی هوش مصنوعی (BFS, DFS, A*)
- **درس:** آزمایشگاه هوش مصنوعی

---

## ساختار پروژه
- `DESIGN.md`: مستند کامل طراحی مسئله، چارچوب PEAS، ویژگی‌های محیط و فرمول‌بندی فضای حالت.
- `lab2_pathfinding.ipynb`: کدهای پیاده‌سازی و ارزیابی الگوریتم‌های جستجو روی نقشه‌ها.
